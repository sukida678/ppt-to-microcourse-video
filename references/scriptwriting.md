# 微课脚本撰写指南

视频好不好看由渲染决定，看不看得下去由脚本决定。这一份是写讲解词的方法。

## 一、时间账先算清楚

| 项目 | 数值 |
|---|---|
| 中文旁白语速（默认 `+0%`） | **≈ 4.5 字/秒**（270 字/分钟） |
| 一页 15 秒 | 约 65 字 |
| 一页 20 秒 | 约 90 字 |
| 一页 30 秒 | 约 135 字 |
| 8 分钟微课 | 约 2150 字，16–22 页 |
| 10 分钟 | 约 2700 字 |

`--rate -8%` 时按 **4.1 字/秒** 算。写完脚本先把字数加一遍，再看总时长对不对——
估算 12 分钟、成片 7 分钟，一定是某几页的 `narration` 写漏了。

**一页超过 180 字就该拆页。** 幻灯片停留 40 秒以上，观众会开始找手机。

## 二、结构模板

### 知识点型（最常用，8–12 分钟）

```
1  钩子      一个具体场景/提问/常见误解          —— 20 秒
2  目录      只说三件事，给出地图                 —— 20 秒
3–7  概念 A  是什么 → 为什么需要 → 怎么工作（举例） —— 各 25 秒
8–9  概念 B  同上，与前一块做对比                 —— 各 25 秒
10  演示      图上走一遍完整流程                   —— 40 秒
11  易错点    学员最常踩的两个坑                   —— 30 秒
12  小结      三句话复述 + 一个思考题              —— 25 秒
```

### 操作演示型（软件/设备）

```
目的 → 前置条件 → 分步骤（一步一页）→ 结果验证 → 出错了怎么办
```
每一步单独一页，旁白只说**这一步做什么、点哪里、看到什么**，不要在一页里塞三步。

### 产品/宣讲型

```
痛点 → 现状做法的问题 → 我们的做法 → 证据（数据/案例）→ 行动号召
```

## 三、写讲解词的六条硬规则

1. **不念幻灯片。** 屏幕上已经写着的字，再用嘴说一遍是浪费观众的时间，也是
   自动朗读机和微课的分界线。幻灯片给"看得懂"，旁白给"听得懂"。
2. **口语，短句。** 一句话一个逗号层，句号切开。避免"综上所述""基于此"。
   写完读一遍——读起来拗口的地方，TTS 一定念得更拗口。
3. **每段一个信息点。** 一段旁白里出现两个"因为"，观众就跟丢了。
4. **符号全部拆成汉字。** `30%` → 百分之三十；`3.5kV` → 三点五千伏；
   `A→B` → 从 A 到 B；`≥` → 大于等于；`/` → 或者（按语境）。
   英文缩写首次出现时给中文：`PLC（可编程逻辑控制器）`，之后再用缩写。
5. **用停顿代替强调。** TTS 不会重音，靠句号、逗号和分页制造节奏。
   需要明显停顿就分页，或者在句末加"——"让人工听感上断开。
6. **结尾不要"谢谢观看"。** 换成一句可复述的总结 + 一个让人动手的问题。

## 四、逐句改写示例

**原始幻灯片文字**

```
PLC 的三大组成
1. 输入单元
2. CPU 运算单元
3. 输出单元
```

**错误写法（念课件）**

> PLC 的三大组成是输入单元、CPU 运算单元、输出单元。

问题：把观众的阅读速度拖到语速，信息量为零。TTS 念出来更明显。

**合格写法**

> 拆开看，PLC 只有三块，跟人干活的方式一模一样。
> 输入单元是它的眼睛和耳朵，开关、传感器、按钮，都从这里进来。
> CPU 是它的大脑，负责判断：该不该动，动多少。
> 输出单元是它的手，指令从这里出去，去推接触器、开阀门、转电机。

**进阶写法（带钩子和因果）**

> 上次有学员问我：PLC 到底贵在哪？拆开这台机器你就明白了。
> 它只有三块——输入端、CPU、输出端，跟人干活一模一样：先看见，再想，最后动手。
> 贵的是中间那块：它得在几毫秒内把几十路信号看完、算完、再决定动不动。
> 人做不到这个速度，所以工厂用它。

## 五、不同学科的偏方

| 类型 | 要点 |
|---|---|
| 工科/设备（PLC、电气、机械） | 先用一个现场故障开场；每个部件配"它坏了会怎样" |
| 软件操作 | 一页一步；说"点哪里"而不是"点击此处所示按钮" |
| 数学/公式 | **不要念公式**，念它的意思；公式留在屏幕上让观众自己看 |
| 语言类 | 例句朗读交给 TTS 的中英混读，旁白只解释用法 |
| 医疗/法规 | 语速降到 `-10%`，关键数字重复一次，结尾强调免责/合规 |
| 历史/人文 | 用时间线做骨架，一页一个转折，少用形容词 |

## 六、写完自检清单

- [ ] 总字数 ÷ 4.5 ≈ 目标时长？（误差 ±15% 内）
- [ ] 有没有哪一页的旁白和幻灯片文字**逐字相同**？
- [ ] 第一页是否在前 10 秒内抛出了问题或利益点？
- [ ] 符号、百分比、单位、缩写是否都改成了汉字读法？
- [ ] 最后一页是否给了可复述的总结，而不是"谢谢观看"？
- [ ] 有没有单页超过 180 字？
- [ ] 静音页（`""`）是不是故意留的？（标题页、纯图页可以留）

## 七、字幕注意事项

- 烧进画面时字号 21、白字黑边、底部留 34px 边距（脚本默认值）。
- 一句话超过 ~22 个汉字就会换行占两行；一行太长会压到画面主体，脚本里就断开。
- `edge-tts` 返回的是**逐词**时间戳，中文按词切分，短句的字幕会更贴合语音。
- 需要外挂字幕（`--subs soft`）时同时产出 `course.mp4` 和 `course.srt`，两个一起交付。
